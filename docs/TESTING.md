# Soon-Cut

螢幕錄影 → 剪頭尾 → 繁中字幕 → 輸出，給 Threads 用的 macOS 浮動工具（自用）。
需求：macOS 15+、Apple Silicon、Xcode 16+。

## 怎麼跑

專案檔用 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 從 `project.yml` 產生（新增檔案後重跑一次 `xcodegen` 即可）。

1. 第一次：`brew install xcodegen`
2. 在這個資料夾執行 `xcodegen`，會產生 `SoonCut.xcodeproj`
3. 用 Xcode 打開 `SoonCut.xcodeproj`
4. Team 已寫在 `project.yml`（DEVELOPMENT_TEAM），重跑 `xcodegen` 不會被清掉。Signing Certificate 要顯示 Development，不能是 Sign to Run Locally
5. 目的地選 `My Mac`，按 ⌘R
6. 第一次錄影時允許「螢幕與系統錄音」權限給 **SoonCut**，然後重新 ⌘R。簽章固定後，之後重新編譯不會再問

錄好的片段存在 `~/Movies/Soon-Cut/Raw/`。

## 開發進度

### 第 1 步：錄影核心 ✅
- [ ] 浮動視窗在最上層，點瀏覽器時影片不會暫停、浮動視窗不會被蓋住
- [ ] 按「範圍」→ 拖曳框選；開「9:16」時框選鎖定 9:16，已有範圍會以中心改成 9:16
- [ ] 按「錄影」（或 ⇧⌘R）→ 範圍外圍出現紅色虛線框，且紅框和浮動視窗都**沒有**被錄進去
- [ ] 再按一次停止 → 片段縮圖出現在「片段」，時長正確
- [ ] 用 QuickTime 打開片段：畫面清楚、有網頁影片的聲音、聲音和畫面同步
- [ ] 右鍵片段可「在 Finder 中顯示」「丟到垃圾桶」

- [ ] 浮動視窗開著、沒在錄影時，範圍外圍有淡淡的虛線框；框選時框會先隱藏；關掉浮動視窗框也會消失，點 Dock 圖示叫回來框再出現

### 第 2 步：WhisperKit 繁中轉寫驗證 ✅（已併入第 4 步的字幕分頁）
第一次執行 Xcode 會下載 WhisperKit 套件（File › Packages › Resolve Package Versions 可手動觸發）。
- [ ] 右鍵片段 →「轉寫字幕（測試）」→ 第一次會下載並準備語音模型（約 1–3 分鐘，需要網路）
- [ ] 轉寫結果出現在「字幕（測試）」區，每句有時間
- [ ] 是繁體字；記下錯字比例（目標：需要手改的句子 ≤ 10%）
- [ ] 記下速度：60 秒片段轉寫 ≤ 15 秒（第二次以後，模型已載入）
- [ ] 試一支有背景音樂的影片，看品質掉多少
### 第 3 步：片段預覽、排序、膠卷條剪頭尾 ✅
新增了檔案，先在資料夾跑一次 `xcodegen` 再 ⌘R。
- [ ] 點片段 → 下方播放；膠卷條顯示 10 張影格
- [ ] 拖左右黃色把手剪頭尾，拖動時預覽跟著跳到該格；放開後播放只播保留的範圍
- [ ] 剪過的片段縮圖時長變黃色；「還原」可取消剪輯
- [ ] 拖曳縮圖可以排序（或右鍵「往前移／往後移」）
- [ ] 重開 App 後順序和剪輯點都還在（存在 Raw/library.json，不動原始影片）
### 第 4 步：字幕編輯與燒入、輸出區（目前這版）
新增了檔案，先跑一次 `xcodegen` 再 ⌘R。預覽上方分頁改成「剪輯｜字幕｜輸出」。
- [x] 「字幕」分頁：全部片段依順序、依剪輯點接起來播放
- [x] 按「產生字幕」→ 轉寫整條時間軸；字幕直接疊在預覽上，跟著播放切換
- [x] 清單裡點時間跳到那一句；直接改字，預覽上的字幕跟著變；可刪除句子
- [ ] 剪輯或排序改變後，出現「建議重新轉寫」提示
- [ ] 按「輸出影片」→ 自動切到「輸出」分頁，新影片在「最新」最上面
- [ ] 用 QuickTime 打開輸出檔：字幕燒在畫面上、時間對、樣式跟預覽一樣
- [ ] 影片卡片拖到 Finder／桌面會複製出檔案；順便試拖進 Threads 網頁的上傳框
- [ ] 「已上傳」按鈕、⋯ 選單移到「封存」、在 Finder 中顯示、丟到垃圾桶都正常

### 第 7 步：多語言字幕（目前這版）
新增了檔案，先跑一次 `xcodegen` 再 ⌘R。
- [ ] 「字幕」分頁多了「語音」與「字幕」兩個選單；預設語音＝中文、字幕＝與語音相同，結果跟以前一樣是繁中
- [ ] 中文影片、字幕選「簡體中文」：直接轉成簡體，不經過翻譯
