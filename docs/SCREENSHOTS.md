# 截圖清單

把截好的圖用**一模一樣的檔名**存到 `docs/images/`，覆蓋佔位圖，README 就會自動顯示。

## 怎麼截

- 截單一視窗：按 **⇧⌘4**，再按**空白鍵**，點要截的視窗（會有好看的陰影）
- 截一塊範圍：按 **⇧⌘4**，拖曳框選
- 存成 PNG，寬度 1400–2000 px 就好

## 內容建議

- 錄你自己的內容：Aicolab 網站、你自己的 App、你自己的教學影片
- **不要用電視新聞、YouTuber、影劇畫面**（著作權，也有真人入鏡）
- 截圖前把桌面、書籤列、通知整理乾淨
